# DORO's Little World

Sty 的个人小站。粉色、手账感，用来放项目、笔记和日常。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 改内容

示例内容都在 `src/data/`：

- `profile.ts` 名字、简介、导航、社交链接
- `projects.ts` 项目
- `posts.ts` 博客
- `moments.ts` 生活记录
- `quotes.ts` 点击角落 DORO 时的随机句子

首页主视觉用的是 `src/assets/doro/doro-hero.png`。如果之后有原版表情包 GIF，可以放到 `public/images/doro/`，再把角落吉祥物的图片地址换过去。
